Squash Tracker began on the watch: an initial commit with basic data
structures and a navigation stack, built to run standalone before a phone
companion existed. Within three weeks a second target was added for the
iPhone app, alongside a CloudKit container to eventually carry match data
between the two. The earliest UI work was mostly navigation and onboarding
scaffolding — nothing that could score a rally yet.
